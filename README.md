## 🚀 Running an exercise

```bash
git clone https://github.com/kfahchai-netizen/PYTHON-IN-CLASS-QUESTION.git
cd PYTHON-IN-CLASS-QUESTION
python 8.8.py        # e.g. the Scrabble scorer
```

`11.4.py` needs a running MySQL server and `pip install mysql-connector-python`. Put your own username and password in the file first.
